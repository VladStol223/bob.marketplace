Download the file at https://vladstol223.github.io/wd.bob/QisBob.yaml and save it as `QisBob.yaml` in my workspace folder.

Then install it as a custom Bob mode by writing it to `.bob/custom_modes.yaml`:

- Windows (PowerShell):
  $lines = Get-Content QisBob.yaml -Encoding UTF8
  $fixed = $lines | ForEach-Object { if ($_ -match '^\s') { $_ -replace '^  ', '' } else { $_ } }
  $out = @("customModes:") + ($fixed | ForEach-Object { "  $_" })
  New-Item -ItemType Directory -Force -Path .bob | Out-Null
  $out | Set-Content .bob/custom_modes.yaml -Encoding UTF8

- macOS / Linux:
  mkdir -p .bob && printf 'customModes:\n' > .bob/custom_modes.yaml && sed 's/^  //' QisBob.yaml | sed 's/^/  /' >> .bob/custom_modes.yaml

Confirm when done and tell me to switch to "QisBob Quantum Mentor" in the Bob mode picker.
